  <name>Task 2: Add day change observers to SlotManager</name>
  <files>PomodoroApp/Models/SlotManager.swift</files>
  <action>
Add triple-redundancy day detection to SlotManager. This builds on the existing idempotent `checkForNewDay()` method which already handles the actual day change logic.

1. Add private properties at the top of the class:
   ```swift
   private var observers: [NSObjectProtocol] = []
   private var midnightTimer: Timer?
   ```

2. In `init()`, after `checkForNewDay()`, call `setupDayChangeObservers()`

3. Add `deinit` to clean up:
   ```swift
   deinit {
       observers.forEach { NotificationCenter.default.removeObserver($0) }
       midnightTimer?.invalidate()
   }
   ```

4. Add `setupDayChangeObservers()` method that sets up four observers:
   - NSCalendarDayChanged (via NotificationCenter.default) - fires at midnight
   - NSWorkspace.didWakeNotification (via NSWorkspace.shared.notificationCenter) - fires on wake from sleep
   - NSSystemTimeZoneDidChange (via NotificationCenter.default) - fires on timezone change
   - Call `scheduleMidnightCheck()` for timer fallback

   All handlers should call `checkForNewDay()` on `.main` queue. Use `[weak self]` capture.

5. Add `scheduleMidnightCheck()` method:
   - Get current Date
   - Use Calendar.current to add 1 day, then get startOfDay for that date (this handles DST correctly)
   - Add 5-second buffer to ensure we're past midnight
   - Calculate timeInterval from now to that fire date
   - Create Timer.scheduledTimer with that interval, repeats: false
   - In handler: call checkForNewDay(), then call scheduleMidnightCheck() again to reschedule

Important: Import AppKit at the top for NSWorkspace access. The file already imports Foundation and SwiftUI.

Reference the research code examples in 01-RESEARCH.md for exact syntax.
